# Ecommerce-MERN-V1
Full Satck MERN ecommerce application with JWT authentication, admin dashboard and with payment method
##  Features

- User authentication (Register / Login)

- JWT-based authorization

- CRUD operations

- MongoDB database integration

- RESTful API structure

---

## Tech Stack

- Node.js

- Express.js

- MongoDB + Mongoose

- JSON Web Token (JWT)

- Dotenv
